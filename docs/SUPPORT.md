## Bug reports

For reproducible defects, prefer [GitHub Issues](https://github.com/Alaa91H/WA-X/issues).

A useful report includes:

1. WA X version or build commit.
2. Android version and device.
3. Target: WhatsApp or WhatsApp Business.
4. Exact target-app version.
5. Steps to reproduce.
6. Expected and actual behavior.
7. Sanitized diagnostics/logs when available.

Do **not** publish phone numbers, JIDs, message contents, API keys, tokens, passwords, signing material or other private data.

## Feature requests

Use the community Feature Requests topic or GitHub Issues when a request needs technical tracking. Explain the user problem first, then the desired behavior and target app/version where relevant.
