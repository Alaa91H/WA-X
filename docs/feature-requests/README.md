# WA X Feature Request Staging

This directory contains **101 issue-ready feature/work-item specifications** extracted from the WA X feature additions prompt (sections 3–102).

GitHub Issues are enabled on `Alaa91H/WA-X`. This branch remains the issue-specification mirror for the live feature requests.

## Import rules

- Create one GitHub Issue per file.
- Use the first Markdown heading as the issue title.
- Use the remainder of the file as the issue body.
- Do not merge unrelated features into one Issue.
- Keep P0/P1/P2/LAB priority in the title or labels.
- Preserve shared quality, compatibility, Stock Mode, privacy, and no-paywall requirements.
